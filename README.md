# JI 스크린골프 도우미 V2.0

GitHub Pages에서 제공하는 퍼팅/필드 공략 계산기 (정적 HTML·JavaScript).

## 구성
- **퍼팅:** 새 퍼팅 에이밍 계산기(거리·경사·에이프런·캐디 컵수, 방향, 매트 자동 확장). 원본의 경험식 유지. 실전 정확도는 사용자 검증 대상.
- **일반필드:** 기존 높낮이·바람·라이 페널티·최종 거리 및 클럽 추천을 유지.
- **설정:** 아이언 3~9, P, 웨지 48/52/56/58 기본 제공. 사용자 클럽을 최대 30개까지 추가·삭제하고 최소·최대 비거리를 저장. 저장된 사용자 클럽도 추천에 포함.
- **인트로:** 5초 후 자동 입장 또는 '바로 시작하기' 즉시 스킵.
- **PWA:** 기존 홈화면 설치와 저장 키 `ji-screen-settings-v1` 유지. 기존 저장된 클럽 비거리·라이 페널티는 그대로 사용.

## 버전 및 캐시 정책
- 앱 버전은 **V2.0**으로 고정하고, 수정 배포마다 **Build YYYYMMDD.NN**을 1씩 증가시킵니다. 현재 Build **20261123.06**.
- 빌드 변경 시 `index.html`의 화면 표시 빌드 번호와 모든 로컬 자원 URL의 `?build=` 값을 함께 올려야 합니다. 동시에 `sw.js` 주석의 빌드 번호도 변경합니다.
- 접속 시 `ji-golf-shell-` 접두어의 기존 앱 캐시만 삭제합니다. 서비스 워커는 앱 리소스를 **network-only / no-store** 방식으로 가져오며 새 캐시를 만들지 않습니다.
- 개인 클럽 및 페널티는 `localStorage`의 `ji-screen-settings-v1`에 보존되며 캐시 정리로 지워지지 않습니다.
- **주의:** 오프라인 실행은 더 이상 보장하지 않습니다. 네트워크가 끊어지면 앱을 새로 열 수 없을 수 있습니다.

## Build 20261123.06 — 다중 매트 좌우 표시 수정
- 매트 1개인 경우 기존 공 마커 표시를 유지합니다.
- 매트가 2개 이상일 경우 현재 매트의 잔여 퍼센트는 **좌측 조준: 오른쪽부터 왼쪽으로**, **우측 조준: 왼쪽부터 오른쪽으로** 측정합니다.
- 예: 133.3%라면 두 번째 매트에서 좌측 조준은 오른쪽부터 33.3%, 우측 조준은 왼쪽부터 33.3%에 공이 표시됩니다.
- 거리·경사·컵수 계산식은 변경하지 않습니다.

## Build 20261123.06 — 우측 컵 다중 매트 공 위치 보정
- 우측 컵에서 두 개 이상 매트가 나올 때 역순 배치는 유지하고, 상단 활성 매트의 공을 **오른쪽 가장자리에서 잔여 퍼센트만큼 안쪽**에 표시합니다.
- 9.2m/우측 11컵 예: 119.6% → 상단 2번 매트 오른쪽 기준 19.6% 위치, 하단 1번 매트 한 칸.
- 오른쪽 컵 다중 매트의 눈금도 공 위치와 일치하도록 내림차순 정렬합니다. 기존 1개 매트 및 좌측 컵 동작은 변경하지 않습니다.
- 퍼팅 계산 공식은 변경하지 않았습니다.

## Build 20261123.06 — 좌측 컵 다중 매트 표시 수정
- 좌측 컵에서 2개 이상 매트가 표시되면 공을 마지막 매트의 **왼쪽 끝에서 잔여 퍼센트만큼** 안쪽에 표시합니다.
- 좌측 컵 119.6% → 2번 매트 왼쪽 기준 19.6%.
- 좌측 컵 눈금은 좌→우 오름차순을 유지합니다. 우측 컵의 역순 매트 배치 및 오른쪽 기준 공 위치는 유지합니다.
