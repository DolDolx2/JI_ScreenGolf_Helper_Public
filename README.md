# JI 스크린골프 도우미 V2.0

GitHub Pages에서 제공하는 퍼팅/필드 공략 계산기 (정적 HTML·JavaScript).

## 구성
- **퍼팅:** 새 퍼팅 에이밍 계산기(거리·경사·에이프런·캐디 컵수, 방향, 매트 자동 확장). 원본의 경험식 유지. 실전 정확도는 사용자 검증 대상.
- **일반필드:** 기존 높낮이·바람·라이 페널티·최종 거리 및 클럽 추천을 유지.
- **설정:** 아이언 3~9, P, 웨지 48/52/56/58 기본 제공. 사용자 클럽을 최대 30개까지 추가·삭제하고 최소·최대 비거리를 저장. 저장된 사용자 클럽도 추천에 포함.
- **인트로:** 5초 후 자동 입장 또는 '바로 시작하기' 즉시 스킵.
- **PWA:** 기존 홈화면 설치와 저장 키 `ji-screen-settings-v1` 유지. 기존 저장된 클럽 비거리·라이 페널티는 그대로 사용.
