# 퍼팅 에이밍 계산기

독립 HTML 웹앱입니다. 기존 `JI_ScreenGolf_Helper_Public` 홈 화면과는 별도 경로로 배포합니다.

- 웹 주소 (GitHub Pages가 main / root 소스로 활성화된 경우): https://doldolx2.github.io/JI_ScreenGolf_Helper_Public/putting-calculator/
- HTML 파일: `index.html`
- 계산식은 원본을 유지했습니다. 매트 개수 자동 확장, 100% 경계 마커, 입력값 검증, 모바일 컵 프리셋, Pretendard CDN 적용.
- 실제 게임에서의 공식 검증은 사용자가 수행합니다.

GitHub Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save 로 Pages를 활성화해야 공개 웹 주소가 동작합니다. 기존 Pages 설정이 다른 배포 소스를 사용한다면 변경 전에 기존 서비스를 확인해야 합니다.
